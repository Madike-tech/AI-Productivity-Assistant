🧠 Prompt Engineering

This project uses structured prompts to improve the quality, consistency and usefulness of AI-generated responses.

Example: Professional Email Prompt

Role: Professional administrative assistant

Task: Generate a professional workplace email.

Context: The email is intended for a professional workplace environment.

Instructions: Use a polite, concise and professional tone. Do not invent information.

Output: Provide a subject line followed by the complete email.

Prompt Engineering Principles Used

  • Clear role definition
  • Specific task instructions
  • Relevant context
  • Defined output format
  • Clear constraints
  • Review and refinement of AI responses
