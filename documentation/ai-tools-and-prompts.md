# AI Tools & Prompt Engineering Examples

## 1. Purpose

AI tools were used during the development of the AI Productivity Assistant to support brainstorming, research, prompt development, testing and productivity.

The project demonstrates how AI can be used as an assistance tool while maintaining human review and responsibility.

---

## 2. AI Tools Used

### ChatGPT

ChatGPT was used to:

- Brainstorm project ideas.
- Develop and improve prompts.
- Generate example workplace scenarios.
- Assist with project documentation.
- Review and improve written content.
- Support troubleshooting during development.

### Gemini

Gemini can be used as an additional AI tool for:

- Research assistance.
- Comparing AI-generated responses.
- Generating alternative ideas.
- Testing different prompt approaches.

### Notion AI

Notion AI can be used for:

- Organising project information.
- Summarising notes.
- Creating task lists.
- Improving productivity and documentation.

# 3. Prompt Engineering Examples

## Email Generation Prompt

### Prompt

You are a professional administrative assistant.

Create a professional workplace email based on the information provided by the user.

Use a polite, concise and professional tone.

Do not invent information that has not been provided.

Include an appropriate subject line followed by the email.

### Expected Output

A clear and professional workplace email that can be reviewed and edited by the user before sending.

---

## Meeting Summarization Prompt

### Prompt

You are an administrative meeting assistant.

Review the meeting notes provided by the user.

Create a concise summary containing:

1. Main discussion points
2. Important decisions
3. Action items
4. Responsible persons, if provided
5. Deadlines, if provided

Do not add information that is not present in the meeting notes.

### Expected Output

A structured meeting summary that is easy to review and share.

---

## Task Planning Prompt

### Prompt

You are a productivity assistant.

Break the user's task into clear and manageable steps.

Identify:

- The main objective
- Priority activities
- Suggested order of completion
- Possible deadlines
- Final review requirements

Keep the recommendations practical and achievable.

### Expected Output

A step-by-step task plan that helps the user complete the activity efficiently.

---

## Research Assistance Prompt

### Prompt

You are a research assistant.

Help the user organise research on the provided topic.

Generate:

- Research questions
- Important keywords
- Main areas to investigate
- Possible challenges
- Suggested information sources

Do not present unverified information as fact.

### Expected Output

A structured research plan that the user can use as a starting point for further investigation.

---

## Chatbot Prompt

### Prompt

You are a helpful workplace productivity assistant.

Assist the user with general administrative and productivity questions.

Provide clear, practical and professional responses.

If information is uncertain, clearly indicate that the user should verify it.

Do not request or expose confidential information.

### Expected Output

A useful and responsible response that assists the user while maintaining human oversight.

---

# 4. Prompt Engineering Techniques Demonstrated

The project uses the following techniques:

### Role

The AI is given a specific role such as:

> Professional administrative assistant.

### Task

The required activity is clearly defined.

### Context

Relevant workplace context is provided.

### Instructions

Specific requirements are given to guide the response.

### Output Format

The desired structure of the response is specified.

### Constraints

The AI is instructed not to invent information or expose confidential information.

---

# 5. Human Review

AI-generated responses should be reviewed by a human before being used for important workplace communication or decision-making.

AI is used as a productivity support tool and does not replace human judgement.

---

# 6. Responsible AI

The project promotes:

- Privacy
- Accuracy checking
- Human oversight
- Ethical AI use
- Responsible information handling
- Appropriate use of AI-generated content
